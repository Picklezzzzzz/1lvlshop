# 1lvlshop — лёгкая витрина из Excel

Для клиентов **без** CloudShop / API: каталог обновляется загрузкой Excel или CSV раз в неделю.

## Демо на Vercel (только витрина)

Без админки и сервера — статическая витрина для ссылки клиенту.

1. Залей репозиторий на GitHub  
2. [vercel.com](https://vercel.com) → Add New Project → Import  
3. Framework: **Other**, Build Command — пусто  
4. Deploy  

Каталог берётся из `data/catalog.json` (через rewrite `/api/products`).  
Админка на Vercel редиректит на главную. Чтобы обновить товары — правь `catalog.json` / `photos/` локально и пушь.  

После деплоя в `index.html` можно прописать `SITE_URL = "https://ваш-проект.vercel.app"` для превью в мессенджерах.

## Запуск

1. Скопируй `.env.example` → `.env`, задай `ADMIN_PASSWORD`
2. `node server.js`
3. Витрина: http://localhost:3010  
   Админка: http://localhost:3010/admin.html

Если PowerShell ругается на `npm`: используй `node server.js` или `npm.cmd run dev`.

## Как обновлять ассортимент

1. Открой `/admin.html`
2. Введи пароль из `.env`
3. Загрузи `.xlsx` / `.csv` (см. `data/sample.csv`)
4. Каталог на сайте обновится сразу

### Колонки

| Колонка | Обязательно | Пример |
|---------|-------------|--------|
| название | да | Торт «Медовик» |
| цена | да | 1650 |
| остаток | нет | 5 |
| категория | нет | торты, выпечка, шоколад, конфеты, наборы |
| фасовка | нет | 1 кг |
| фото | нет | `ekler.jpg` или `/photos/cake.jpg` |
| описание | нет | Медовые коржи со сметанным кремом |
| состав | нет | мука, яйца, мёд… |
| аллергены | нет | глютен, яйцо, молоко |

Английские заголовки (`name`, `price`, `cat`…) тоже работают.

Фото **не** вшиваются в Excel: загружайте в админке или кладите в `photos/`, в таблице — имя файла или путь.

## Отличие от Зоомир (CloudShop)

| | Зоомир | 1lvlshop |
|--|--------|----------|
| Источник | API CloudShop | Excel/CSV |
| Обновление | авто | руками через админку |
| Фото | из учёта (когда подключим) | ссылка / папка photos |

## Настройка витрины

В `index.html` блок «НАСТРОЙКИ МАГАЗИНА»:

- `SHOP_NAME`
- `WHATSAPP_PHONE`
- `HIDE_ZERO_STOCK` — скрывать нулевые остатки
