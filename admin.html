Прайса и фото для демо-кондитерской. Сайт: на витрину

1. Прайс Excel / CSV

Заменяет весь каталог на сайте.

2. Фото товаров

Загрузите картинки сюда, нажмите «Копировать путь» и вставьте в колонку фото в Excel. Можно писать просто имя файла, например ekler.jpg.

Колонки в Excel / CSV
  • название — обязательно
  • цена — обязательно, число > 0
  • остаток — сколько в наличии (0 можно скрыть на витрине)
  • категория — торты / выпечка / шоколад / конфеты / наборы
  • фасовка — например 1 кг, 1 шт, 200 г
  • фото — имя файла после загрузки выше, напр. ekler.jpg
  • описание — текст в кнопке «i» на карточке
  • состав — по желанию
  • аллергены — по желанию

Готовый пример: sample.csv (откройте или скачайте). Старые английские заголовки (name, price, cat…) тоже работают.
